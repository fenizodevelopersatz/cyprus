To move this project from test/dev networks to mainnet, change both .env and the Admin Signal Assets records, because your code gives admin asset fields priority over env defaults.
Already Mainnet
Ethereum and BSC are already mainnet in exchange-backend/.env:
env



SPOT_TESTNET=false
FUT_TESTNET=false
ETH_RPC_URL=https://mainnet.infura.io/v3/...
BSC_RPC_URL=https://bsc-dataseed.binance.org
ETH_API_URL=https://api.etherscan.io
BSC_API_URL=https://api.bscscan.com

Change Solana Devnet To Mainnet
Replace:
env



NETWORK=devnet
SOLANA_NETWORK=devnet
SOLANA_RPC_URL=https://api.devnet.solana.com
SOLANA_USDC_MINT=4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU
SOLANA_TOKEN_MINT=4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU

with:
env



NETWORK=mainnet
SOLANA_NETWORK=mainnet
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
SOLANA_USDC_MINT=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v
SOLANA_TOKEN_MINT=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v

Change TRON Nile To Mainnet
Replace:
env



TRX_API_URL=https://nile.trongrid.io
TRON_FULL_HOST=https://nile.trongrid.io

with:
env



TRX_API_URL=https://api.trongrid.io
TRON_FULL_HOST=https://api.trongrid.io

Use a mainnet TRON API key for:
env



TRX_API_TOKEN=your_mainnet_trongrid_api_key

Check Admin Panel Signal Assets
In Admin Dashboard → Coin / Signal Assets, update each asset:
ERC20: Ethereum mainnet RPC, USDT contract 0xdAC17F958D2ee523a2206206994597C13D831ec7
BEP20: BSC mainnet RPC, USDT contract 0x55d398326f99059fF775485246999027B3197955
TRC20: TRON mainnet host https://api.trongrid.io, USDT contract TXLAQ63Xg1NAzckPwKHvzw7CSEmLMEqcdj
SOLANA: chain/network mainnet, USDC mint EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v
Important: if the admin asset table still says devnet, nile, or test mint, it can override your .env.
After changes, restart backend:
powershell



cd exchange-backend
npm run dev

Then watch logs for rpc_connected and confirm chain IDs:
Ethereum: 1
BSC: 56
Solana: mainnet / mainnet-beta
TRON: should no longer show nile or shasta
Do this carefully: existing devnet/Nile wallets and user deposit addresses are not automatically valid balances on mainnet. Mainnet needs real funded admin gas wallets and correct private keys.
